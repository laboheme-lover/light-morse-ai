# 光モールス信号AI翻訳(light-morse-ai)

スマホのランプの点滅(和文モールス信号)を R10 で撮った動画から、点滅している光源を自動で見つけて、
文章として読み取るアプリ。音のモールス信号のアプリ(`../morse-ai`)と同じ考え方で作った。

- 光源: R8 のランプ(短点 約300ms)、撮影: R10(1920×1080、約30.3コマ/秒)
- 読み取る文字: 65文字(音の63文字 + 括弧「（」「）」)。区切り「」」は句点「。」と同じ符号なので「。」として読む

## 仕組み

| 段階 | 処理 | プログラム |
|---|---|---|
| 光源を見つける | 明るさの揺れが大きく、点灯/消灯の2値に分かれる小さな領域を探す。動く光(細長い通り道)と、規則正しく点滅し続ける光(警告灯など)は点数を下げる。候補を点数順に返す | `light_roi.py` |
| 明るさを取り出す | 選んだ領域の明るい上位10%のピクセルの平均を1コマずつ | `light_roi.py` |
| 1文字ずつに区切る | 点灯/消灯を判定し、短点の長さを動画全体から測り、2単位以上の消灯で区切る | `light_sequence.py` |
| 文字を判定する | 明るさの列を「1単位 = 6点」にそろえた144点の列にし(`light_features.py`、学習と共通)、畳み込み+双方向GRUのモデル(約11万パラメータ)で65文字のどれかにする | `light_features.py`, `light_model.py` |
| 画面 | 動画の場所を入力 → 候補の光源を枠で表示(選び直せる)→ 文章・波形・文字ごとの詳細 | `app.py` |

## 学習データ

実際の動画(1文字ずつ65本)の測定(`measure_clips.py`)に合わせて、ランプの明るさの列を合成する(`light_synth.py`)。

- カメラの写り方: 露光時間・ランプの点き方(10〜40ms)と消え方(1〜5ms)・明るさの振り切れを再現。
  点灯の始めのコマの明るさが実際と合うことを確かめた(中央値 0.90)
- 送る速さ: 短点 0.15〜0.6秒、長さの揺らぎ ±10%
- 悪条件(`light_synth.add_conditions`): 夕方・明け方、霧、雨、背景の光、カメラ(露出の変化・手ぶれ・コマ落ち)。
  20%は雑音なし、残りは1〜3個を重ねる
- 65文字 × 300件 = 19,500件、学習70% / 検証15% / テスト15%(`generate_light_dataset.py`)

映像に悪条件をかける処理(`light_augment.py`)は、光源の検知を実際の動画で確かめるために使う。

## 結果(65文字のモデル)

| データ | 結果 |
|---|---|
| 実際の文章の動画 20本(学習にも調整にも使っていない) | 20本すべて文字一致率 100%(括弧を含む) |
| 実際の文章の動画 original44 の残り 29本(65文字のモデルを作った後に初めて評価) | 29本すべて文字一致率 100%(2,830文字) |
| 文章の動画 20本に映像の悪条件をかけたもの(20本 × 6条件、光源と短点の長さも測り直す) | 120件すべて光源を正しく見つけ、文字一致率 100%(8,442文字) |
| 実際の1文字の動画 65本 | 65 / 65 |
| 実際の1文字の動画に映像の悪条件をかけたもの(65本 × 6条件) | 95.9%(光源を正しく見つけた件は 100%。誤りは、ゆっくり点滅する光との取り違え) |
| 合成テスト(雑音なし / 悪条件1つ / 2つ / 3つ) | 100% / 99.7% / 93.3% / 72.4% |

実際の動画は、どれも暗い室内でランプを固定して撮ったもの。雨・霧・夕方は合成した効果で確かめただけで、
本物の悪条件の動画での確認はまだしていない。
文章の動画の悪条件では、夕方・霧で点灯と消灯の明るさの差が約半分(232 → 117〜141)になった。雨・背景の光源・雑音はランプの明るさにはほとんど影響せず、主に光源の検知(おとりに引っかからないか)を試している。
1文字の動画より成績が良いのは、光源を探す最初の60秒に長短の並びが何十文字分も写り、規則正しく点滅するおとりと区別しやすいため。

## 使い方

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 学習データを作って学習する(CPUで約10分)
.\.venv\Scripts\python.exe generate_light_dataset.py
.\.venv\Scripts\python.exe train_light.py --epochs 30

# アプリ
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8503 --server.maxUploadSize 1024

# テスト
.\.venv\Scripts\python.exe -m pytest -q
```

評価のスクリプト: `measure_clips.py`(実際の動画の測定)、`evaluate_real_singles.py`(1文字65本)、
`evaluate_augmented_singles.py`(映像の悪条件をかけた65本)、`evaluate_sentences.py`(文章の動画)、
`evaluate_augmented_sentences.py`(映像の悪条件をかけた文章の動画)。

`morse_table.py` は音のプロジェクト(`../morse-ai/morse_table.py`)の写し。文字と符号の表を音と揃えるため、変更しないこと。
